Middleware — Verification du role admin (commun a toutes les operations)

sequenceDiagram participant Admin as Admin participant FE as Frontend
(Next.js) participant API as API PHP
(middleware.php) participant DB as MySQL
(users, sessions) Admin->>FE: Effectuer operation CRUD FE->>FE: authFetch()
Ajouter header Authorization FE->>API: Requete API
Headers: Authorization: Bearer base64(42:email:hmac) API->>API: 1. set_cors_headers()
2. init_session() API->>API: 3. check_rate_limit('admin_services') API->>API: 4. require_admin() alt Session PHP valide API->>API: Verifier $_SESSION['user_id'] API-->>API: User ID = 42 else Token Bearer API->>API: Base64 decode → [42, email, hash] API->>API: hash_hmac('sha256', '42:email', secret) API->>API: hash_equals(expected, hash) end API->>DB: SELECT id, name, email, role
FROM users WHERE id=42
AND email='admin@manom.com' DB-->>API: {id:42, role:'admin'} alt role !== 'admin' API-->>FE: 403 {error: "Admin access required"} FE-->>Admin: Refuse — acces interdit else role === 'admin' API-->>API: Autorisation OK
Continuer le traitement end

1. CREATE — Creer un service

sequenceDiagram actor Admin participant FE as Frontend
(Next.js) participant API as API PHP
(services.php) participant DB as MySQL
(services) Admin->>FE: Cliquer "Ajouter un service" FE-->>Admin: Afficher formulaire
(titre, description, duree, prix) Admin->>FE: Remplir et soumettre
Titre: "Goutte a Goutte"
Description: "Soin du cuir chevelu"
Duree: 30min
Prix: 30 MAD FE->>FE: Validation cote client
(champs non vides) FE->>API: POST /api/admin/services.php
Headers: Authorization: Bearer token
Body: {
titre: "Goutte a Goutte",
description: "Soin du cuir chevelu",
duree: 30,
prix: 30
} API->>API: Middleware:
require_admin() → OK API->>API: Verifier champs requis
['titre', 'duree', 'prix'] API->>API: sanitize_input(titre)
htmlspecialchars + trim API->>API: Valider duree
(5 <= duree <= 480) API->>API: Valider prix
(prix >= 0) API->>DB: INSERT INTO services
(titre, description, duree, prix)
VALUES ("Goutte a Goutte",
"Soin du cuir chevelu", 30, 30.00) DB-->>API: Last Insert ID = 7 API-->>FE: 201 Created
{message: "Service cree", id: 7} FE->>FE: Rafraichir liste des services FE-->>Admin: Service ajoute avec succes

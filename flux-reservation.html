Etape 1 : Verification de la disponibilite du barbier

(Next.js) participant API as API PHP
(slots.php) participant DB as MySQL
(barber_availability, bookings, services) Client->>FE: Selectionne barbier + date + service FE->>API: GET /api/bookings/slots.php
?barber_id=2&date=2026-06-15&service_id=1 API->>API: Valider parametres
(barber_id, date, service_id) API->>DB: SELECT duree FROM services
WHERE id=1 AND active=1 DB-->>API: duree = 45 minutes API->>DB: SELECT jour_semaine FROM
barber_availability
WHERE barbier_id=2
AND jour_semaine = 1
AND actif=1 DB-->>API: Barbier disponible le lundi API->>DB: SELECT heure_debut, heure_fin
FROM barber_availability
WHERE barbier_id=2 AND jour_semaine=1 DB-->>API: 09:00 → 20:00 API->>DB: SELECT heure_rdv, s.duree
FROM bookings b

AND b.date_rdv='2026-06-15'

Etape 3 : Verification des conflits (Transaction)

sequenceDiagram participant FE as Frontend
(Next.js) participant API as API PHP
(create.php) participant DB as MySQL
(transactions) FE->>API: POST /api/bookings/create.php
Headers: Authorization: Bearer token
Body: {service_id:1, barbier_id:2,
date_rdv:'2026-06-15',
heure_rdv:'14:00'} API->>API: 1. Verifier authentification
(session ou token HMAC) API->>DB: SELECT id, duree, prix
FROM services WHERE id=1
AND actif=1 DB-->>API: Service OK (45min, 45 MAD) API->>DB: SELECT id FROM barbers
WHERE id=2 AND actif=1 DB-->>API: Barbier OK API->>DB: SELECT id FROM
barber_availability
WHERE barbier_id=2
AND jour_semaine=1
AND '14:00' BETWEEN
heure_debut AND heure_fin DB-->>API: Disponible API->>API: BEGIN TRANSACTION API->>DB: SELECT id FROM bookings
WHERE barbier_id=2
AND date_rdv='2026-06-15'
AND heure_rdv='14:00'
AND statut IN ('pending','confirmed')
FOR UPDATE DB-->>API: Aucun conflit direct API->>API: Calculer heure_fin =
14:00 + 45min = 14:45 API->>DB: SELECT b.id FROM bookings b
JOIN services s ON b.service_id=s.id
WHERE b.barbier_id=2
AND b.date_rdv='2026-06-15'
AND b.statut IN ('pending','confirmed')
AND b.heure_rdv < '14:45'
AND ADDTIME(b.heure_rdv,
SEC_TO_TIME(s.duree*60)) > '14:00'
FOR UPDATE DB-->>API: Aucun chevauchement API-->>API: Verifications OK

Flux d'Authentification Complet

1. Inscription (Sign Up)

sequenceDiagram actor Utilisateur participant FE as Frontend
(Next.js) participant API as API PHP
(signup.php) participant DB as MySQL
(table users) Utilisateur->>FE: Ouvrir /auth → onglet Inscription FE-->>Utilisateur: Afficher formulaire
(nom, email, mot de passe, confirmer) Utilisateur->>FE: Remplir et soumettre le formulaire FE->>FE: Validation cote client
(champs vides, mot de passe different) FE->>API: POST /api/auth/signup.php
Body: {name, email, password} API->>API: check_rate_limit('signup') API->>API: validate_required(['name','email','password']) API->>API: validate_email(email) API->>API: password_hash(password, BCRYPT) API->>DB: SELECT id FROM users WHERE email = ? DB-->>API: NULL (email disponible) API->>DB: INSERT INTO users (name, email, password, role)
VALUES (?, ?, hash, 'client') DB-->>API: Last Insert ID = 42 API->>API: Generer token HMAC:
base64(42:email:hmac_sha256) API->>DB: INSERT INTO sessions (id, user_id, ip_address, user_agent, payload, last_activity) DB-->>API: OK API-->>FE: 201 Created
{token, user: {id:42, name, email, role:'client'}} FE->>FE: localStorage.setItem('manom_auth', JSON.stringify({token, user})) FE-->>Utilisateur: Rediriger vers /dashboard

2. Connexion (Sign In)

sequenceDiagram actor Utilisateur participant FE as Frontend
(Next.js) participant API as API PHP
(login.php) participant DB as MySQL
(tables users, sessions) Utilisateur->>FE: Ouvrir /auth → onglet Connexion FE-->>Utilisateur: Afficher formulaire
(email, mot de passe) Utilisateur->>FE: Remplir et soumettre le formulaire FE->>API: POST /api/auth/login.php
Body: {email, password} API->>API: check_rate_limit('login') API->>API: validate_required(['email','password']) API->>DB: SELECT id, name, email, password, role
FROM users WHERE email = ? DB-->>API: {id:42, name:'Ahmed', email:'a@b.com',
password:'$2y$10$...', role:'client'} API->>API: password_verify(password, hash) alt Mot de passe incorrect API-->>FE: 401 {error: 'Email ou mot de passe incorrect'} FE-->>Utilisateur: Afficher erreur else Mot de passe correct API->>API: Generer token HMAC:
base64(42:email:hmac_sha256('42:email')) API->>DB: INSERT INTO sessions
(id, user_id, ip_address, user_agent, payload, last_activity) DB-->>API: OK API-->>FE: 200 OK
{token, user: {id:42, name, email, role}} FE->>FE: localStorage.setItem('manom_auth', JSON.stringify({token, user})) FE-->>Utilisateur: Rediriger vers /dashboard ou /admin end

3. Authentification Requete (Token Verification)

sequenceDiagram participant FE as Frontend
(Next.js) participant API as API PHP
(middleware.php) participant DB as MySQL
(tables users, sessions) FE->>API: GET /api/admin/stats.php
Header: Authorization: Bearer base64(42:email:hmac) API->>API: init_session() API->>API: Verifier Session PHP
$_SESSION['user_id'] alt Session non valide API->>API: Parser header Authorization API->>API: Base64 decode → [userId, email, hash] API->>API: hash_hmac('sha256', '42:email', secret) API->>API: hash_equals(expected, hash) alt Token invalide API-->>FE: 401 {error: 'Authentication required'} else Token valide API->>DB: SELECT id, name, email, role
FROM users WHERE id=42 AND email='a@b.com' DB-->>API: {id:42, name, email, role:'admin'} alt Role insuffisant API->>API: require_admin() → role !== 'admin' API-->>FE: 403 {error: 'Admin access required'} else Autorisation OK API->>API: Continuer le traitement API-->>FE: 200 OK (donnees) end end end

4. Mot de Passe Oublie (Forgot Password)

sequenceDiagram actor Utilisateur participant FE as Frontend
(Next.js) participant API as API PHP
(forgot-password.php) participant DB as MySQL
(tables users, password_resets) Utilisateur->>FE: Cliquer "Mot de passe oublie?" FE-->>Utilisateur: Afficher formulaire email Utilisateur->>FE: Entrer email et soumettre FE->>API: POST /api/auth/forgot-password.php
Body: {email: 'a@b.com'} API->>API: check_rate_limit('forgot_password') API->>API: validate_email(email) API->>DB: SELECT id, name FROM users WHERE email = ? DB-->>API: {id:42, name:'Ahmed'} API->>DB: UPDATE password_resets SET used=1
WHERE user_id=42 AND used=0 DB-->>API: OK API->>API: Generer token: bin2hex(random_bytes(32)) API->>API: Calculer expiration: now + 1 heure API->>DB: INSERT INTO password_resets
(user_id, token, expires_at)
VALUES (42, 'a1b2c3...', NOW()+1h) DB-->>API: OK API-->>FE: 200 OK
{message: 'Lien genere', token: 'a1b2c3...', expires_in: 3600} FE-->>Utilisateur: Afficher le token (mode dev)

5. Reinitialisation du Mot de Passe (Reset Password)

sequenceDiagram actor Utilisateur participant FE as Frontend
(Next.js) participant API as API PHP
(reset-password.php) participant DB as MySQL
(tables users, password_resets) Utilisateur->>FE: Entrer token + nouveau mot de passe FE->>API: POST /api/auth/reset-password.php
Body: {token, password} API->>API: check_rate_limit('reset_password') API->>API: validate_required(['token','password']) API->>DB: SELECT id, user_id, expires_at, used
FROM password_resets WHERE token = ? DB-->>API: {id:7, user_id:42, expires_at:'...', used:0} API->>API: Verifier expiration (expires_at > NOW()) API->>API: Verifier si deja utilise (used = 0) alt Token expire ou utilise API-->>FE: 400 {error: 'Token invalide ou expire'} else Token valide API->>API: password_hash(new_password, BCRYPT) API->>DB: UPDATE users SET password = ? WHERE id = 42 DB-->>API: OK API->>DB: UPDATE password_resets SET used=1 WHERE id=7 DB-->>API: OK API->>DB: DELETE FROM sessions WHERE user_id = 42 DB-->>API: OK API-->>FE: 200 OK
{message: 'Mot de passe reinitialise'} FE-->>Utilisateur: Rediriger vers /auth → Connexion end
